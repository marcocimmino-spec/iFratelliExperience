# I Fratelli del Vesuvio

Landing page for the "I Fratelli del Vesuvio" full-day Vesuvius + pizza experience (Positano).

Static single-page site — no build step. Deploys as-is on Vercel.

## Structure

- `index.html` — the whole site (HTML + CSS + JS inline)
- `hero.jpg` — hero background
- `gallery-1.jpg` … `gallery-5.jpg` — gallery photos
- `gallery-video.mp4` — gallery video
- `con-casa-3.jpg` — "Who We Are" photo

## Deploy on Vercel via GitHub

1. Create a new GitHub repo and push this folder's contents to it.
2. In Vercel: **New Project** → import the repo.
3. Framework preset: **Other** (no build command, output directory = root).
4. Deploy.

## Local preview

```bash
python -m http.server 8090
# open http://localhost:8090/
```
